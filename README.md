# 📱 App com Abas — Flutter

Aplicativo desenvolvido em **Flutter** como atividade acadêmica da disciplina de **Desenvolvimento para Dispositivos Móveis**.

O projeto demonstra a utilização de **abas de navegação** para organizar diferentes seções dentro de um mesmo aplicativo, permitindo que o usuário alterne entre conteúdos de forma simples e intuitiva.

## 🚀 Funcionalidades

O aplicativo possui três seções principais:

### 🏠 Início
- Mensagem de boas-vindas;
- Imagem carregada pela internet;
- Interface simples e personalizada.

### 📰 Notícias
- Lista de notícias fictícias;
- Exibição organizada através de `ListView`;
- Numeração das notícias;
- Cards com título e indicação de notícia fictícia.

### 👤 Perfil
- Foto de perfil carregada pela internet;
- Nome do usuário;
- Informações acadêmicas;
- Exibição circular da imagem.

## 🧩 Tecnologias e recursos utilizados

- **Flutter**
- **Dart**
- `StatefulWidget`
- `StatelessWidget`
- `TabBar`
- `TabBarView`
- `TabController`
- `ListView.separated`
- `Image.network`
- `initState()`
- `dispose()`
- Material Design

## 🎨 Interface

Cada aba possui uma identidade visual própria:

| Aba | Ícone | Cor |
|---|---|---|
| 🏠 Início | Home | Azul |
| 📰 Notícias | Newspaper | Verde |
| 👤 Perfil | Person | Laranja |

Essa organização facilita a navegação e diferencia visualmente cada seção do aplicativo.

## 📚 Objetivo do projeto

O objetivo é desenvolver um aplicativo Flutter utilizando **abas de navegação**, praticando a organização da interface em diferentes seções e o gerenciamento do estado necessário para controlar a navegação entre elas.
